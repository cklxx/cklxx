# AGENT Guide

## Compounding Retrospective
- When a task is completed, use compounding engineering to review what we did and extract reusable lessons from past experience.

## Rule Capture and Tooling
- During the retrospective, identify the steps taken and mistakes made.
- Decide whether to:
  - write a rule
  - write a skill
  - require it as mandatory pre-reading next time
  - create a script or rule library
- Put verified, workable items into the toolbox.

## Quality Requirements
- Fully verify lint and test.

## Coding Constraints
- Avoid unnecessary defensive code.
